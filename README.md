# Alchemist-Dungeon
ポーション調合ハック＆スラッシュ『アルケミスト・ダンジョン』
概要: 武器を振って戦うのではなく、ダンジョン内で拾った素材をリアルタイムに調合して強力な薬品や爆弾を作りながら突き進むハクスラ系ローグライク。

ゲームシステム:

モンスターを倒したり採取ポイントから「赤・青・緑・紫」などの元素素材を獲得。

「赤＋赤＝爆発薬」「赤＋青＝氷結陣」「緑＋紫＝毒霧」のように、状況に合わせて即座にスロットで組み合わせを作って投擲・散布する。

敵の弱点属性に合わせて調合レシピを素早く切り替えるスピーディーな判断が鍵。

ローグライク要素: 毎回変わる「素材の相性ランダム化」や、拠点に戻って釜を強化する永続育成要素。
