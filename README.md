# Alchemist Dungeon (アルケミスト・ダンジョン)

ダークファンタジー調のリアルタイム調合＆化学コンボ・アクションローグライトゲーム。

## ゲーム概要

- **火 (Pyr)**, **水 (Aqua)**, **地 (Terra)**, **闇 (Nox)** の4大元素を採取・収集
- 坩堝（Crucible）に元素を投入し、瞬時に戦術ポーション/爆弾を調合・投擲
- 敵の弱点属性（ダメージ2倍）と耐性（ダメージ半減）を突いた戦略的戦闘
- フロア踏破後の「錬金術師の休息所」で坩堝容量拡張（2スロット→3スロット）、採取効率強化、秘伝書解放
- Web Audio API によるシンセサイズド・プロシージャルサウンド

## 主な調合レシピ

- **火 + 火** = **インフェルノ・ボム** (広範囲大爆発 + 火傷付与)
- **水 + 水** = **フロスト・ショック** (敵の移動を3秒間氷結停止)
- **火 + 水** = **スチーム・スカルド** (高熱蒸気による貫通 + ノックバック)
- **火 + 地** = **ポイズン・クラウド** (毒煙霧エリア展開 + 継続ダメージ)
- **水 + 地** = **ヒーリング・エリクサー** (即座にプレイヤーHP回復)
- **火 + 闇** = **ヘルファイア** (HP自傷を代償とする単体超火力)
- **水 + 闇** = **ヴァンピリック・ドレイン** (敵からHPを吸収)
- **地 + 闇** = **アシッド・スプラッシュ** (腐食強酸により敵防御力を半減)
- **火 + 水 + 地** = **プリズマティック・ノヴァ** (3元素核融合による全画面超衝撃波)

## 操作方法

- **移動**: [W] [A] [S] [D] または 矢印キー
- **元素選択**: [1] 火 / [2] 水 / [3] 地 / [4] 闇 (クリックでも可能)
- **ポーション投擲**: 左クリック または [Space] キー
- **元素採取**: 鉱床近くで [E] キー (画面右上ボタンでも可)
- **坩堝リセット**: [C] キー
- **錬金術式録 (図鑑)**: [B] キー

## 開発・実行

```bash
# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build
```
